# Глоссарий и компоненты TrueBeam/VitalBeam

> **Примечание:** Документ составлен на основе открытых источников (официальные материалы Varian/Siemens Healthineers, публикации AAPM, рецензируемые статьи). Перед использованием в сервисных целях необходима сверка с официальными руководствами по обслуживанию конкретной версии системы. Сомнительные факты отмечены ⚠️.

## 1. Аббревиатуры и термины

**MU — Monitor Unit (Мониторная единица).** Единица дозы, выдаваемой ускорителем. 1 MU обычно соответствует 1 cGy в воде на глубине максимума при стандартных условиях калибровки. Счётчик MU — главный критерий прекращения подачи пучка.

**MLC — Multi-Leaf Collimator (Многолистовой коллиматор).** Устройство динамического формирования поля из множества тонких вольфрамовых листьев с индивидуальными приводами. Два варианта: **Millennium 120** (центральные 40 листьев по 5 мм, остальные 80 по 10 мм, поле до 40×40 см) и **HD120** (32 центральных листа по 2,5 мм, остальные по 5 мм, поле до 22 см, для SRS/SBRT). ВНИМАНИЕ: MLC = Multi-Leaf Collimator, НЕ «Multiple Leaf Controller».

**IMRT — Intensity-Modulated Radiation Therapy.** Модуляция интенсивности пучка перемещением листьев MLC; режимы Step-and-Shoot и Sliding Window.

**VMAT — Volumetric Modulated Arc Therapy.** Доставка дозы во время вращения гантри; у Varian — **RapidArc**. Одновременно меняются скорость гантри, скорость дозы и положение MLC.

**SRS / SRT / SBRT.** Стереотаксическая радиохирургия (1 фракция) / фракционированная (2–5) / для экстракраниальных мишеней (высокие дозы, 1–5 фракций, строгий IGRT-контроль).

**IGRT — Image-Guided RT.** Визуальный контроль укладки: kV-рентген, CBCT, MV, EPID; коррекция столом PerfectPitch.

**CBCT — Cone-Beam CT.** Объёмная рентгеновская томография на аппарате коническим пучком (система OBI).

**OBI — On-Board Imager.** kV-визуализация: трубка 40–150 кВ (фокус 0,4 мм) + плоскопанельный детектор на роботизированных консолях под 90° к пучку; SAD 100 см.

**EPID — Electronic Portal Imaging Device.** a-Si детектор напротив MV-пучка; на TrueBeam — **aS1200** (сцинтиллятор GOS, шаг 0,336 мм); верификация поля и портальная дозиметрия.

**DRR — Digitally Reconstructed Radiograph.** Синтетический рентген из планирующей КТ; эталон для сопоставления с kV/MV-снимками.

**FFF — Flattening Filter Free.** Режим без выравнивающего фильтра: 6 MV FFF до 1400 МЕ/мин, 10 MV FFF до 2400 МЕ/мин; «конический» профиль; для SRS/SBRT и VMAT.

**RPM — Real-time Position Management.** Дыхательный гейтинг: ИК-камера + маркерный блок; включение/отключение пучка в заданной фазе.

**MPC — Machine Performance Check.** Встроенная автоматическая проверка QA (выход ±1%, однородность ±2%, центр пучка ±0,5 мм, MLC, изоцентр, гантри/стол); ~10 мин.

**VSP — Virtual Source Position.** Кажущееся положение источника электронного пучка; машинно-зависимая величина.

**SAD — Source-to-Axis Distance.** Источник→изоцентр; на TrueBeam = 100 см.

**SSD — Source-to-Skin Distance.** Источник→кожа пациента.

**DLG — Dosimetric Leaf Gap.** Эффективный зазор закрытых листьев MLC; учитывается в расчёте IMRT-дозы.

**HyperArc** — комплекс для интракраниальной SRS с несколькими изоцентрами (TrueBeam STx + HD120). **HyperSight** — улучшенный CBCT при сниженной дозе для адаптивного планирования. **OSMS** — оптический контроль поверхности пациента. **DIBH** — глубокая задержка дыхания (отведение сердца при раке молочной железы).

## 2. Аппаратные компоненты

- **Электронная пушка** — термоэмиссионная триодная, катод ~−18 кВ; импульсная инжекция электронов в волновод.
- **СВЧ-источник** — магнетрон (~2 МВт, низкие энергии) или клистрон (>7 МВт, высокие энергии), ~3000 МГц.
- **Ускоряющий волновод** — вакуумная структура (~10⁻⁷ Торр), ускоряет электронные сгустки.
- **Изгибающий магнит 270°** — перенаправляет пучок к мишени, фокусирует по энергии.
- **Мишень (вольфрам)** — генерирует тормозное излучение; убирается в электронном режиме.
- **Выравнивающий фильтр** — сглаживает профиль (WFF); убирается в FFF.
- **Мониторные ионизационные камеры** — двойные, измеряют MU/скорость дозы/симметрию; первичная защита по дозе.
- **Коллиматор**: первичный (неподвижный) + джо X1/X2, Y1/Y2 (асимметричные) + MLC.
- **Стол PerfectPitch 6DoF** — X/Y/Z/Rtn + pitch/roll (±3,0°), нагрузка до 200 кг, изоцентрично.
- **Maestro** — распределённая система управления; узлы координируются супервизором; контроль каждые 10 мс.
- **Фантом IsoCal** — для MPC: BB-маркер для расчёта изоцентра излучения и визуализации.

### OBI (kV) — параметры
Трубка 40–150 кВ, фокус 0,4 мм; SAD 100 см; SID 100–182,5 см; детектор a-Si 40×30 см, 2048×1536, 14 бит; шаг 0,2/0,4 мм; CBCT в режиме Dynamic Gain.

### EPID aS1200
Сцинтиллятор GOS + a-Si; шаг 0,336 мм; отклонение дозового отклика <0,5% (2–10 MU), <1% (>10 MU).

## 3. TrueBeam vs VitalBeam

Обе платформы — одна аппаратная архитектура и система Maestro. VitalBeam — более доступная для стандартной терапии; TrueBeam — универсальная (терапия + радиохирургия).

| Характеристика | TrueBeam | VitalBeam |
|---|---|---|
| Позиционирование | Терапия + радиохирургия | Терапия (оптимизирована) |
| Фотонные энергии | 6/10/15 МВ + 6/10 FFF | до 3 по выбору |
| Электронные | 6/9/12/15/18 МэВ | до 6 (конфигурируемо) |
| MLC | Millennium 120; HD120 (STx) | Millennium 120; HD120 (опция) |
| Макс. скорость дозы | 600 (WFF); 1400 (6FFF); 2400 (10FFF) | аналогично |
| OBI/CBCT | встроено | опционально |
| EPID | aS1200 | aS1200/aS1000 |
| SRS/HyperArc | да (STx) | ограниченно ⚠️ |

> ⚠️ Конкретная конфигурация зависит от заказа и версии ПО.

## 4. Режимы пучка и энергии

**Фотоны:** 6X/10X/15X (WFF, ~600 МЕ/мин); 6X FFF (1400); 10X FFF (2400); 2,5 MV (MV-визуализация). ⚠️ 18/25 МВ — нестандартные конфигурации.

**Электроны:** 6/9/12/15/18 МэВ; своя комбинация рассеивающих фольг и конусов на энергию; для поверхностных мишеней.

**FFF-особенности:** конический профиль, высокий выход, более сильная зависимость от размера поля; для SRS и VMAT.

**Гейтинг/4D:** RPM прерывает пучок вне фазы дыхания; 4D CBCT синхронизирует проекции по фазам → расчёт ITV.

## 5. Программные системы

- **Eclipse (TPS)** — планирование (AAA, AcurosXB), DRR, оптимизация IMRT/VMAT/SRS.
- **ARIA (OIS)** — онкологическая ЭМК; хранит планы, MLC-архивы, дозовые листы, результаты MPC; интеграция с TrueBeam.
