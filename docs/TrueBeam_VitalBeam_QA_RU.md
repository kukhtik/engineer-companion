# Калибровка и контроль качества (QA) TrueBeam/VitalBeam

> Составлено из открытых источников (отчёты AAPM, материалы Varian, рецензируемые публикации). Требует сверки с официальными руководствами. Неподтверждённые данные помечены [?].

## 1. Machine Performance Check (MPC)
Встроенное приложение TrueBeam (с v2.0); автоматическая оценка по геометрии и дозиметрии через EPID (MV) и OBI (kV), без оператора. [PMC4464869]

**Проверки постоянства пучка** (по каждой энергии FF/FFF; MV-изображение 18×18 см² при SDD 150 см, 40 МЕ):
- Выход (Beam Output Change): ±1%
- Однородность (Beam Uniformity): ±2%
- Смещение центра пучка: ±0,5 мм

> MPC НЕ заменяет ежемесячную проверку абсолютного выхода ионизационной камерой.

**Геометрические проверки** (фантом **IsoCal** — цилиндр ~23 см с 16 W-карбидными BB 4 мм). Полная сессия — 39 изображений (12 kV + 27 MV); ~5,6 мин/энергию.

| Тест | Что | Допуск |
|---|---|---|
| Размер изоцентра излучения | «шар изоцентра» по MV при 8 углах (через 45°) | ±0,5 мм |
| Совпадение MV/kV изоцентров | пространственное несовпадение | ±2,0 мм |
| Угол гантри / коллиматора | starshot | ±1° [?] |
| Позиция джо (18×18) | — | ±1 мм |
| MLC (Enhanced check) | точность / воспроизводимость | ±1,0 / ±0,5 мм |
| Люфт MLC (backlash) | — | ±0,4 мм |
| Кушетка | LAT/LNG/VRT, угол, pitch/roll | ±2,0 мм / ±0,5° [?] |

MPC — **ежедневно** перед первой сессией; не отменяет периодические проверки физика по TG-142.

## 2. Абсолютная дозиметрическая калибровка (TG-51)
Протокол AAPM для абсолютной дозы в воде (междунар. аналог — TRS-398 МАГАТЭ).

Эталонные условия: вода; фотоны — глубина 10 см, поле 10×10, SSD 100, камера Farmer; электроны — d_ref=0,6·R₅₀−0,1, плоско-параллельная камера для E<6 МэВ.

Формула: **D_w = M · k_Q · N_D,w^(60Co)**, где M — показание камеры с поправками (T, P, рекомбинация, полярность); N_D,w — калибровочный коэффициент (ADCL); k_Q — фактор качества через %dd(10)_x.

Выполняет **квалифицированный медицинский физик**. Когда: приёмка, ввод в эксплуатацию, после ремонта дозообразующих компонентов, ежегодно (TG-142, допуск ±1%), по показаниям отклонений.

## 3. Геометрический QA и изоцентричность

**Winston-Lutz** — «золотой стандарт» совпадения механического и радиационного изоцентров (критично для SRS/SBRT). Малый BB в изоцентре, малое поле, серия снимков при разных углах гантри/коллиматора/кушетки → 3D-погрешность. Допуски: TrueBeam SRS/SBRT ≤1 мм; TG-179 ±2 мм для IGRT. Off-iso WL — для мишеней >6–7 см от изоцентра.

**Star-shot** — ось вращения гантри/коллиматора; ≤1 мм для SRS/SBRT (в MPC автоматически).

**Лазеры (TG-142):** ежедневно ±2/±2/±1 мм (не-IMRT/IMRT/SRS); ежемесячно ±2/±1/±1.

**Углы (ежемесячно):** гантри/коллиматор ±1,0°; кушетка ±1,0° (±0,5° для SRS/SBRT).

## 4. QA визуализации
Совпадение изоцентров OBI/EPID/лечения — критично для IGRT (IsoCal в MPC; WL с kV; допуск ≤2 мм, желательно ≤1 мм для SRS).
CBCT качество (фантом **Catphan**, ежемесячно): пространственное и контрастное разрешение, однородность HU, геометрические искажения, шум — по базовой линии. Калибровка смещения OBI в MPC (±2 мм [?]).

## 5. Регулярный QA по TG-142

**Ежедневно** (терапевт): выход фотонов/электронов ±3%; лазеры ±2/±1,5/±1 мм; ODI ±2 мм; размер поля ±2/±2/±1 мм; все блокировки (двери, E-Stop, монитор).

**Ежемесячно** (физик): выход (ИК) ±2%; резервная камера ±2%; профиль ±1%; энергия электронов ±2%/±2 мм; свет/радиация поле симм. ±2 мм / асимм. ±1 мм; углы гантри/коллиматора ±1,0°; кушетка ±2 мм/±1,0° (±1 мм/±0,5° SRS); позиции джо симм. ±2 / асимм. ±1 мм.

**Ежегодно** (физик): абсолютная калибровка TG-51 ±1%; малые поля <4×4 ±2%, ≥4×4 ±1%; качество пучка ±1%; линейность MU ≥5 MU ±2%, 2–4 MU ±5%; выход vs угол ±1%; VMAT ±1%; плоскостность/симметрия ±1%; R₅₀ ±1 мм; изоцентр (раздельно) ±1 мм; совпадение изоцентров ±2 мм (±1 SRS); провисание кушетки ±2 мм.

## 6. QA многолистового коллиматора (MLC)

**Picket fence** (на EPID) — узкие поля-«штакетины»; поперечные отклонения листьев видны как нарушения прямолинейности. Допуски: точность позиции ±1 мм (TG-142, IMRT, ежемесячно); воспроизводимость ±0,5 мм; люфт ±0,4 мм (Varian). На TrueBeam воспроизводимость ~0,04 мм (3 SD), чувствительность ~0,28 мм. [Kalavagunta 2022, PMC11799905]

Доп.: MLC speed/travel [?]; interdigitation (HD120); пациент-специфический QA (MapCHECK/ArcCHECK/Delta4 — косвенно). Enhanced MLC Check в MPC — ежедневно центральные 40 пар Millennium-120; полный picket fence — еженедельно/ежемесячно.
